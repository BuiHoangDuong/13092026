# Exchange logo assets

Bybit and Binance retain the existing project PNG assets. MEXC uses the official
dark-background horizontal lockup from the [MEXC Brand Hub](https://www.mexc.com/en-GB/brand-guidelines),
converted from WebP to transparent PNG without changing its proportions:
https://static.mocortech.com/image-host/index/lockup-horizontal-lightblue.be49f020be85.webp

Logos identify exchanges; they do not establish verified offer terms. Serve these
files locally using Exchange.logoUrl; do not depend on third-party image hosting.
